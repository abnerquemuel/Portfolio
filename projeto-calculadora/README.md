# Calculadora

Calculadora web simples feita com HTML, CSS e JavaScript.

## Funcionalidades

- Operacoes basicas: soma, subtracao, multiplicacao e divisao
- Porcentagem
- Botao de limpar
- Botao de apagar o ultimo digito
- Suporte ao teclado
- Layout responsivo

## Como abrir

Abra o arquivo `index.html` no navegador.

## Tecnologias

- HTML
- CSS
- JavaScript
