# Snake

Jogo Snake feito para navegador com HTML, CSS, JavaScript e Canvas.

## Funcionalidades

- Fundo escuro
- Cobrinha verde
- Comida vermelha
- Maca roxa especial que vale 3 macas normais
- Inimigo que aparece de vez em quando e persegue a cobra
- Placar
- Botao Jogar/Reiniciar
- Controle pelo teclado e por botoes no celular
